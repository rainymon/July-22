전체 본문을 모두 넣으면 읽을 시간이 부족합니다.

- 같은 분의 기사는 번호 순서대로 0.045초씩만 어긋나게 출력
- 6, 100, 162번 본문 카드: 각 1.5초 정지
- 176번 마지막 카드: 3초 정지

## 녹화
1. 데스크톱 브라우저에서 앱을 엽니다.
2. `F`로 작품 화면을 전체화면으로 만듭니다.
3. 화면 녹화를 시작합니다.
4. `R`을 눌러 처음부터 시작합니다.
5. 176번 카드가 나온 뒤 녹화를 종료합니다.
