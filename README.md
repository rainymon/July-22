# 2019.07.22 기사 타임라인 — 시간·캡처 크기 수정 버전

## 반영된 변경 사항

- 001, 006, 100, 161, 162, 176 캡처를 모두 001번과 같은
  `996 × 2048 px` 화면으로 통일했습니다.
- 모든 캡처는 상단에 고정되며 스크롤하지 않습니다.
- 타임라인 선은 00:00부터 24:00까지의 하루 전체를 뜻합니다.
- 14:13은 선의 약 59.24%, 23:09는 약 96.46% 위치에 표시됩니다.
- 진행 막대와 상단 타이머도 같은 24시간 기준으로 움직입니다.
- 특수 기사 캡처가 표시되는 순간 타이머가 실제 발행 시각에 정확히 멈춥니다.
- 176번은 기사 제목 목록에 추가하지 않고 캡처만 표시하며,
  마지막 화면으로 계속 남습니다.
- `재생 시작` 버튼은 `전체화면` 버튼 바로 옆에 있습니다.
