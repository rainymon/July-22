# 2019.07.22 기사 타임라인 — 캡처 축소·제목 이동 수정 버전

## 변경 사항

- 기사 캡처는 원본 비율을 유지합니다.
- 캡처 가로폭을 기존 대비 70% 줄여, 화면 폭의 30%로 중앙 상단에 표시합니다.
- 전체 작품 화면은 기존 대비 약 80% 크기로 줄였습니다.
- 새 기사가 나오면 기존 제목이 한 단씩 위로 올라갑니다.
- 현재 기사는 흐리지 않게 굵은 글씨로 제목 전문이 표시됩니다.
- 동일 시각의 기사도 타이머는 그대로 유지한 채 프레임별로 빠르게 순서대로 표시됩니다.
- 176번은 제목 목록에 넣지 않고 기사 캡처만 표시합니다.
- 176번 캡처가 끝나면 제목과 캡처를 모두 지운 흰 화면에서
  타이머와 진행 막대가 24:00까지 계속 움직입니다.
- 전체 재생시간은 1분 미만입니다.
