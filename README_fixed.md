# 2019.07.22 기사 타임라인 — 본문 입력 완료 버전

## 포함된 본문 카드
- 001
- 006
- 100
- 161
- 162
- 176

본문은 제공된 링크의 핵심 내용을 1분 미만 세로 영상에 맞춰 요약했습니다.
기사 전문을 그대로 복제한 것은 아닙니다.

## 재생시간
- 실제 00:00~23:09 간격을 49초에 선형 압축
- 006, 100, 161, 162번 카드에서 각 1.5초 정지
- 마지막 176번 카드에서 3초 정지
- 전체 약 59초

## 배포
ZIP 안의 아래 두 파일을 GitHub 저장소 최상단에 올리세요.

- streamlit_app.py
- requirements.txt

기존 파일을 두 파일 모두 교체한 뒤 Streamlit Cloud에서 Reboot app을 실행하세요.

## 재생
1. 화면 중앙의 `재생 시작` 클릭
2. 다시 시작은 상단 버튼 또는 `R`
3. 전체화면은 버튼 또는 `F`
