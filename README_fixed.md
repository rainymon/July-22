# 재생 오류 수정 버전

이 버전은 `st.html()` 대신 JavaScript가 iframe에서 실행되는
`streamlit.components.v1.html()`을 사용합니다.

## 업로드할 파일

ZIP 안의 다음 파일을 GitHub 저장소 최상단에 올리세요.

- `streamlit_app.py`
- `requirements.txt`

기존 파일을 남겨두지 말고 두 파일 모두 교체한 뒤 Streamlit Cloud에서
**Reboot app**을 실행하세요.

## 재생

1. 페이지가 열리면 작품 화면 중앙의 **재생 시작**을 클릭합니다.
2. 다시 시작하려면 상단의 **다시 시작** 버튼을 클릭합니다.
3. 키보드가 작동하지 않을 때는 반드시 화면 또는 버튼을 한 번 클릭한 뒤 사용합니다.
4. 전체화면은 **전체화면** 버튼으로 실행합니다.
